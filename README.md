# The effect of bit collisions  

This repository contains the code for the paper "Size matters - how bit length of molecular fingerprints determines the reliability of computational tools in environmental chemistry and toxicology"


## contents

data folder - contains two of the used datasets: pesticide degradation & chemical inventory

bitcollisions.ipynb contains information on self-collision counts in the datasets and the effect on similarity searching 

the src folder contains the source code for the machine learning models
of which the outputs an be found as json files in the results folder

lastly, all figures can be found in the assets folder
